# Grip It and Rip It

A pixel-art roguelite about throwing a paper airplane as far as you can.

**Play it:** https://mwelliott.github.io/grip-it-and-rip-it/

- **Throw:** hold the mouse (or Space) to grip, aim, and let go in the gold band for a PERFECT.
- **Fly:** hold the mouse / Up / W to pull up, Down / S to dive. Space, Shift or right-click for a gust.
- **Drafts:** 1-3 or click to pick.

Built from 7b90a9a. This repo only holds the build.
